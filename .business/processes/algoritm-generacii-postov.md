# Регламент: Алгоритм генерации постов по Лестнице Ханта

Метод создания контента для Telegram, ВК, Дзен и блога Ice Studio.

## 1. Определение ступени Ханта
- **Уровень 1 (Боль и неосознанность):** Проблема сохранения страниц без искажения стилей. Встроенная печать браузера режет шрифты, таблицы и дашборды.
- **Уровень 2 (Поиск решений):** Сравнение вариантов: ручной скриншотер vs сторонние веб-сервисы vs расширение для Chrome.
- **Уровень 3 (Выбор продукта):** Преимущества Website to PDF (сохранение стилей пиксель-в-пиксель, поддержка 54 языков, работа без водяных знаков).
- **Уровень 4 (Покупка):** Оффер PRO-версии или бесплатная установка из Chrome Web Store с российской кассой Prodamus.

## 2. Структура поста
1. **Хук (1-2 предложения):** Жесткий факт, уязвимость или знакомая проблема без вводных слов.
2. **Мясо (2-3 абзаца):** Техническая суть проблемы (CSS print media query, обрезка canvas, искажение шрифтов).
3. **Решение (список):** Пошаговый вывод или показ работы расширения.
4. **CTA:** Призыв с кодовым словом или ссылка на лендинг.

## 3. Фильтр стиля
- Только дефисы `-`, никаких длинных тире.
- Абзацы по 1-3 предложения.
- Отсутствие машинных штампов.
